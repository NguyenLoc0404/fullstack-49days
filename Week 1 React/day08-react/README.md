# Day 8 — React Greeting Card

## Giới thiệu

Ứng dụng React hiển thị thẻ chào hỏi với tên,
vai trò, avatar và lời chào theo thời gian trong ngày.

## Công nghệ

- React
- Vite
- JSX
- CSS

## Cài đặt và chạy

```bash
npm install
npm run dev
```

## Tính năng

- Tái sử dụng GreetingCard Component
- Truyền dữ liệu bằng Props
- Lời chào theo giờ địa phương
- Giá trị dự phòng khi thiếu tên hoặc vai trò
- Xử lý ảnh avatar không tải được
